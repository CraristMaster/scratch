Programming Strategy

Any programmer can solve problems by following a simple strategy. Use these steps whenever you define a new program:

  1. Understand the problem: Read the requirements and decide what inputs and outputs are needed.
  2. Break it down: Divide the program into small tasks like "read number", "compute", and "show result."
  3. Write the logic: Use formulas and simple code to compute the answer.
  4. Test it: Try sample values and verify the output is correct.
  5. Improve: Make the interface clearer and handle invalid or missing values.

For this tool:

  • Density = mass ÷ volume
  • Fahrenheit = Celsius × 9/5 + 32
  • Kelvin = Celsius + 273.15
